順路の計算

下のGoogle連携を設定していれば、この2つはほとんど使われません。 実測値がまだ無い区間だけ、この値で概算します。数kmの移動は市街地で遅く、20km超は幹線道路で 速くなるため2段階に分けています。

Googleマップの実測所要時間未設定

ここで一度キーを入れれば、担当者は何も意識せずに実測値で計算されます。 取得した所要時間は保存され、共有中ならほかの担当者にも自動で配られます。 場所を追加したときも、順路を作るときに足りない区間だけ自動で取りに行きます。 キーを入れなければ、直線距離からの概算で動きます。

ふだんは押す必要はありません。渋滞事情が変わったときなどに使ってください。

課金事故を防ぐ設定を必ず。 Google Cloud コンソールで、このキーに ①「ウェブサイトの制限」でこのアプリのURLのみ許可 ②「Routes API」のみ許可 ③1日の割り当て上限、を設定してください。 キーはこの端末のブラウザにのみ保存され、どこにも送信されません。

Firebase の準備手順
  1. Firebase コンソールで「プロジェクトを追加」
  2. 「Firestore Database」→「データベースの作成」→ 本番環境モード
  3. 「Authentication」→「始める」→「匿名」を有効にする
  4. Firestore の「ルール」を下記に置き換えて公開
  5. 「プロジェクトの設定」→ マイアプリ →「ウェブ」を追加し、表示された設定を上の欄に貼る
